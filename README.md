# HoverInfo — 高亮信息显示

一个为 Minecraft 基岩版打造的准星指向信息增强 Add-On。看向方块、生物、掉落物时，屏幕顶部实时显示详细中文信息——支持方块状态、附魔、熔炉燃料、耕地湿度、生物属性等 30+ 项信息，且**完全不触碰玩家背包**。

> 基于 MIT 开源项目 [WAILA](https://github.com/r4isen1920/WAILA) 改进。展示名不含任何第三方商标。

---

## 🎮 支持版本

- **Minecraft 基岩版 1.21 ~ 1.26**
- **无需开启实验性玩法**，直接导入即可使用

---

## ✨ 功能特性

### 🧱 方块信息（蹲下显示详细信息）
- 方块名称（中文，支持本地化 key）
- **方块状态全中文**（朝向/生长/点亮/湿度…100+ 状态名映射）
- 作物生长进度（x/最大 + 百分比）
- 耕地湿度（直接检测 4 格内水源，而非读取不可靠状态值）
- 堆肥桶填充、蜂窝蜂蜜量、炼药锅水量、蜡烛数量与点亮状态
- 红石信号强度、中继器延迟、音符盒音调
- 熔炉/高炉/烟熏炉：**冶炼状态 + 燃料名 + 可烧时长 + 正在烧制的物品**（全部中文）
- 海龟蛋孵化状态、末地传送门框架、重生锚充能、方块所需工具提示

### 👤 生物信息
- 生物名称（中文）
- 血条（心形/数值，自适应）
- 幼年 / 已驯服 / 驯服几率 / 充能（苦力怕）/ 已剪毛
- **坐骑奔跑速度**（方块/秒：马/驴/骡/骆驼/猪/炽足兽）
- 僵尸村民转化中状态 + 药水效果列表

### 💎 掉落物信息
- 物品名称（中文）+ 数量
- **附魔显示**：内置 40+ 附魔中文映射 + 罗马数字等级，每个附魔独立一行
- 自定义命名物品

### 🖼️ 图标系统
- 900+ 方块/物品**原版平面图标**（16×16，官方 client.jar 提取）
- 生物 3D 模型渲染（不依赖背包）
- Flat/3D 双模式资源子包可切换

### 🛡️ 安全性
- **完全不碰玩家背包**：禁用容器镜像机制，杜绝物品丢失/错乱
- 日志静默（不刷聊天框）
- 签名去重优化（详细信息变化即时刷新）

## 📥 安装

1. 前往 [Releases](https://github.com/liuaotou/HoverInfo/releases) 下载最新版本
2. 双击 `.mcaddon` 文件导入 Minecraft（或通过文件管理器打开）
3. 在全局资源/行为包中启用
4. 进入世界即可使用：**平时**看基础信息，**蹲下（潜行）**看详细信息

> ⚠️ 安装前请先删除手机上所有旧版本（R4.x 及更早），否则多个行为包共存会导致 UI 崩溃。

## 🔧 与原版 WAILA 的改动

本项目基于原版 [WAILA](https://github.com/r4isen1920/WAILA)（MIT 开源）进行了以下改进：

- **全面中文化**：方块状态名、附魔名、设置界面全部中文（原版为英文/部分多语言）
- **自定义图标系统**：原版方块纹理全部替换为官方平面图标，尺寸和风格统一
- **掉落物附魔显示**：原版无附魔信息，新增 40+ 附魔中文映射 + 罗马数字等级
- **熔炉/生物详情**：燃料信息、坐骑速度、转化状态等额外信息
- **自定义封面**：替换原版通用图标为用户自制封面
- **朝向重复修复**：同一方块多个朝向状态只显示一行中文（原版会显示数值+中文两行）
- **禁用容器镜像**：从根源杜绝物品丢失 bug，完全不碰玩家背包
- **签名去重**：避免信息刷新卡顿

## 🛠️ 构建（开发者）

```bash
cd packs/data/gametests
npm install
npm i -D esbuild
npx esbuild src/main.ts --bundle --format=esm --target=es2022 --minify \
  --external:@minecraft/server --external:@minecraft/server-ui \
  --outfile=../../BP/scripts/main.js
```

无需 Regolith，纯 npm + esbuild 构建。

## 📁 项目结构

```
packs/
├── BP/                    # 行为包（manifest + texts）
└── RP/                    # 资源包（UI + 图标纹理 + Flat/3D 子包）
data/gametests/src/
├── main.ts                # 入口
└── waila/
    ├── core/              # 核心逻辑（方块/生物/容器）
    └── utils/             # 中文映射（状态名/附魔名）
```
